PHISHING CLASSIFIER OPTIMIZATION
RUN INSTRUCTIONS
============================================================

PROJECT:
phishing-classifier-optimization

PURPOSE:
This project evaluates the impact of hyperparameter optimization
on the accuracy-latency trade-off of phishing classifiers.

The experimental pipeline consists of:

1. Data preprocessing
2. Baseline model training
3. GridSearchCV optimization
4. Optuna optimization
5. Final evaluation and comparison


============================================================
1. PROJECT STRUCTURE
============================================================

phishing-classifier-optimization/

IMPORTANT:

All Python scripts are located inside the src/ directory.

common.py contains shared configuration, paths, hyperparameter
search spaces, and utility functions.

Do NOT run common.py directly.


============================================================
2. OPEN THE PROJECT
============================================================

Open the project folder in VS Code.

The terminal should be opened at the project root:

phishing-classifier-optimization/

Verify the current location:

pwd

or in PowerShell:

Get-Location


============================================================
3. CREATE THE VIRTUAL ENVIRONMENT
============================================================

If .venv does not exist:

python -m venv .venv

Activate the environment:

.\.venv\Scripts\Activate.ps1

After activation, the terminal should show:

(.venv)

at the beginning of the command line.


============================================================
4. INSTALL DEPENDENCIES
============================================================

python -m pip install -r requirements.txt


============================================================
5. VERIFY THE ENVIRONMENT
============================================================

Run:

python -c "import numpy, pandas, sklearn, xgboost, optuna, joblib; print('Environment OK')"


============================================================
6. RUN THE PIPELINE IN ORDER
============================================================

From the project root with .venv activated:

1. Preprocessing:
python src/data_preprocessing.py

2. Baseline Training:
python src/train_baseline.py

3. GridSearchCV Optimization:
python src/train_gridsearch.py

4. Optuna Optimization:
python src/train_optuna.py

5. Final Evaluation:
python src/evaluate.py --dataset <dataset_name> --experiment <E1-E6> --model <model_filename>


============================================================
7. COMPLETE COMMAND SEQUENCE
============================================================

.\.venv\Scripts\Activate.ps1

python -m pip install -r requirements.txt

python src/data_preprocessing.py

python src/train_baseline.py

python src/train_gridsearch.py

python src/train_optuna.py
