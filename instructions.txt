PHISHING CLASSIFIER OPTIMIZATION
RUN INSTRUCTIONS
============================================================

PROJECT:
phishing-classifier-optimization

PURPOSE:
This project evaluates the impact of hyperparameter optimization
on the accuracy-latency trade-off of phishing classifiers.

The experimental pipeline consists of:

1. Data preprocessing and canonical splitting
2. Baseline model training (E1, E4)
3. GridSearchCV optimization (E2, E5)
4. Optuna optimization (E3, E6)
5. Final model evaluation and comparison

============================================================
2. ENVIRONMENT SETUP
============================================================

Open the project folder in VS Code, open the terminal at the project root, and run:

python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt


============================================================
3. RUN THE PIPELINE IN ORDER
============================================================

1. Preprocessing (Generates 80/20 train/test joblib splits):
python src/data_preprocessing.py

2. Baseline Model Training (E1, E4):
python src/train_baseline.py

3. GridSearchCV Optimization (E2, E5):
python src/train_gridsearch.py

4. Optuna Optimization (E3, E6):
python src/train_optuna.py

5. Model Evaluation (Batch runner):
python src/run_evaluation.py


============================================================
4. FILE NAMING CONVENTIONS
============================================================

- Processed Splits: data/processed/{dataset}_split.joblib
- Trained Models: models/{dataset}_{experiment}_{classifier_name}.joblib
- Training Logs: results/training/{dataset}_{experiment}_training.json
- Evaluation Reports: results/evaluation/evaluation-result-1/{dataset}-evaluation-result/
